# KingDoc — 金山文档 AI 协作助手

> 让 AI 直接操作你的金山在线文档，创建、编辑、管理一站搞定。
> **v3.9.0**：块级编辑（段落级在线编辑，block_id CRUD）· 演示页替换（双路径自动选择 + 页数校验）· 配额管理器（SQLite 按天计数 + 令牌桶限速 5 req/s + 429 退避）· 格式转换全格式覆盖（jpg/png/txt 补齐，pdf/jpg/png/txt/docx/xlsx/pptx/html/md）· 智能画布元素级精细编辑（对标腾讯文档·智能画布）· 空间节点管理增强（目录树/链接节点/递归删除）· 文档内容全文搜索（超越腾讯：搜内容+结果定位高亮）· 多维表格视图增强（看板/日历/甘特图，对标 Airtable）· 手写/公式识别 OCR（教育场景，LaTeX/MathML 输出）· 历史管理（回收站+版本历史统一入口）· 深度直连 WPS 开放平台原生 API · 文档模板市场（行业模板库一键复用）· WPS AI 深度集成（段落级改写/总结/续写）· 实时协同编辑（序列 CRDT，多人无冲突）· 文档对比（差异高亮/变更摘要/导出）· 文档内容合规检查（敏感词/泄露/格式/密级）· 协同编辑冲突解决（检测/合并/diff/解决）· WPS AI 能力（写作/分析/PPT/阅读）· 硬件自适应性能 · 免密钥本地能力。

## 🚀 快速开始

### 1. 安装

```bash
# Linux / macOS
bash D:\skill\kingdoc\setup.sh
# Windows (PowerShell)
powershell -ExecutionPolicy Bypass -File D:\skill\kingdoc\setup.ps1
```

### 2. 配置 App Key（仅云端协作需要）

从 [金山开放平台](https://developer.kdocs.cn) 获取 AppID + AppSecret，安装脚本引导输入。
**本地生成/OCR/硬件画像/WPS AI 无需 Key。**

### 3. 直接使用

对 WorkBuddy 说：
- "帮我写一份会议纪要" → 本地生成并上传
- "把这个 PDF 传到云端" → 上传（自动拦截禁止类型）
- "这份文档改坏了，回退到上周" → 版本回滚
- "识别这张发票的文字" → 本地 OCR（免密钥）
- "帮我润色这段文字" → WPS AI 写作辅助（免密钥）
- "分析这列数据的趋势" → WPS AI 数据分析（免密钥）
- "根据大纲生成 PPT" → WPS AI PPT 生成（免密钥）
- "总结这份文档" → WPS AI 阅读助手（免密钥）
- "把多维表格显示为看板" → 多维表格视图增强（免密钥）
- "识别这个数学公式" → 公式识别 OCR（免密钥）
- "恢复回收站里的文件" → 历史管理（需 App Key）

## 🧠 性能（不拖累电脑）

首次运行自动采集硬件并分配并发子进程数：

| 机器档位 | 并发子进程 | 批量分块 |
|---------|-----------|---------|
| 低端（≤2核/<4GB） | 1 | 50 |
| 普通 | min(核数,4) | 200 |
| 高端（≥8核/≥16GB） | min(核数,8) | 500 |

## 🚫 安全：禁止上传的文件类型

用户上传默认拦截：`.bat .cmd .ps1 .vbs .exe .dll .lnk .msi`、
`.docx .xlsx .pptx .doc .xls .ppt .xlsm .docm .pptm`、
`.iso .dmg .zip .rar .7z .tar .gz .apk .jar`、
`.DS_Store .git .env .log .tmp`、`.sh .com .scr .hta .reg`。
技能内部生成的 docx/pptx/pdf/svg 等经豁免通道上传。
