# 企业文档格式规范

## 字体规范
- 正文：宋体，12pt
- 一级标题：黑体，18pt，加粗
- 二级标题：黑体，15pt，加粗
- 三级标题：宋体，13pt，加粗
- 英文/数字：Times New Roman

## 段落规范
- 行距：1.5倍行距
- 段前：0行
- 段后：0行
- 首行缩进：2字符

## 页边距
- 上：2.54cm
- 下：2.54cm
- 左：3.17cm
- 右：3.17cm

## 标题层级
- 一、（一级标题）
- （一）（二级标题）
- 1.（三级标题）
- （1）（四级标题）

## 其他
- 正文每行不超过80字符
- 长文档必须有 H1 标题
- 图表必须有编号和标题
