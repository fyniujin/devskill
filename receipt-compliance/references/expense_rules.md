# 费用分类规则

本文件定义了根据发票/票据内容自动匹配费用类型的规则。

## 关键词匹配规则

| 费用类型 | 触发关键词 |
|---------|-----------|
| 差旅费 | 酒店、住宿、机票、火车票、高铁、动车、打车、出租车、滴滴 |
| 办公费 | 办公用品、文具、打印、复印、耗材、电脑、鼠标、键盘 |
| 业务招待费 | 餐饮、食品、招待、餐厅、饭店、酒楼 |
| 广告费 | 广告、推广、宣传、营销、品牌、投放 |
| 咨询费 | 咨询、顾问、法律、审计、税务代理 |
| 交通费 | 打车、出租车、滴滴、公交、地铁 |
| 通行费 | 通行费、高速、桥闸、过路费 |
| 福利费 | 福利、员工、生日、节日、体检 |
| 租赁费 | 租赁、房租、物业、水电 |
| 维修费 | 维修、修理、维护、保养 |

## 按票据类型直接分类

| 票据类型 | 默认费用类型 |
|---------|-------------|
| 火车票 | 差旅费 |
| 飞机行程单 | 差旅费 |
| 出租车票 | 交通费 |
| 通行费票据 | 通行费 |
| 财政票据 | 财政票据（不可抵扣） |
